📋 How to Fix HMS Authentication

Step 1: Set Backend Environment Variable

Go to your backend deployment platform:

  • Render: Dashboard → Service → Environment → Add ALLOW_HMS_BYPASS=true
  • Railway: Project → Variables → Add ALLOW_HMS_BYPASS=true
  • Heroku: App → Settings → Config Vars → Add ALLOW_HMS_BYPASS=true

Step 2: Restart Backend

After adding the variable, restart your backend service.

Step 3: Test

Use this page to test if HMS bypass is working.

Why This is Needed

HMS doesn't have a login system yet, so we use a temporary token bypass. The backend needs ALLOW_HMS_BYPASS=true to accept hms_temp_token.
