## 🔐 QR Code Generation Process

### 1. **Unique Identifier Generation**
```typescript
// Location: backend/src/modules/hms/services/qrService.ts

const qrCodeId = `QR-${Date.now()}-${crypto.randomBytes(4).toString('hex').toUpperCase()}`;
```

**This creates**: `QR-1717477200000-A1B2C3D4`
- `QR-` - Prefix
- `1717477200000` - Current timestamp (milliseconds) - UNIQUE per generation
- `A1B2C3D4` - 8 hex characters from crypto.randomBytes(4) - RANDOM

**Uniqueness Guaranteed**: Timestamp + Random bytes = No two QR codes are the same!

---

### 2. **Encrypted Payload**
```typescript
const payload = {
  qrCodeId: 'QR-1717477200000-A1B2C3D4',  // Unique ID
  patientId: 'PAT-001',                    // Patient link
  timestamp: '2026-06-04T10:00:00Z',       // Generation time
  version: 1                               // QR version
};
```

---

### 3. **HMAC-SHA256 Signature**
```typescript
const signature = crypto
  .createHmac('sha256', QR_SECRET_KEY)
  .update(JSON.stringify(payload))
  .digest('hex');
```

**This creates**: `a3f7b2c4d5e6f8a9b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e6f7a8b9c0d1e2f3a4`

**Security**: 
- Secret key based
- Impossible to forge without secret
- Can only be generated by backend

---

### 4. **Base64 Encoding**
```typescript
const qrData = Buffer.from(
  JSON.stringify({
    qrCodeId: 'QR-1717477200000-A1B2C3D4',
    patientId: 'PAT-001',
    timestamp: '2026-06-04T10:00:00Z',
    version: 1,
    signature: 'a3f7b2c4d5e6f8a9...'
  })
).toString('base64');
```

**Final QR Data**: `eyJxckNvZGVJZCI6IlFSLTE3MTc0NzcyMDAwMDAtQTFCMkMzRDQiLCJwYX...`

## 🔍 Validation Process (HMS Scan)

### Step 1: Decode Base64
```typescript
const decoded = JSON.parse(Buffer.from(qrData, 'base64').toString('utf-8'));
```

### Step 2: Verify Signature
```typescript
const expectedSignature = crypto
  .createHmac('sha256', QR_SECRET_KEY)
  .update(JSON.stringify({ qrCodeId, patientId, timestamp, version }))
  .digest('hex');

const isValid = crypto.timingSafeEqual(
  Buffer.from(signature, 'hex'),
  Buffer.from(expectedSignature, 'hex')
);
```

**If signature doesn't match → INVALID QR CODE**

### Step 3: Check Database
```typescript
const qrCode = await QRCode.findOne({ qrCodeId });
```

### Step 4: Check Expiry
```typescript
if (qrCode.expiresAt < new Date()) {
  return { valid: false, reason: 'QR code has expired' };
}
```

### Step 5: Check Status
```typescript
if (qrCode.status === 'USED') {
  return { valid: false, reason: 'QR code already used' };
}
```
